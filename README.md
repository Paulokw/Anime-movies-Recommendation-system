# Anime-movies-Recommendation-system
This is a Content-based Recommendation system for Anime movies/shows that gives the top 10 best anime recommendations depending on the anime selected.
We will be using a dataset from kaggle, the TF-IDF model common with NLP use cases together with cosine similarity to draw up similarities between the various movies.
For data preprocessing, I dealt with missing values and applied regular expressions to ensure data quality.
